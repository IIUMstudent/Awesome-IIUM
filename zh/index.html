欢迎来到 Awesome-IIUM！

欢迎！我们非常高兴能为您呈现这一系列专为马来西亚国际伊斯兰大学（IIUM）社区精心策划的资源。无论您是在校学生、尊敬的教职员工，还是引以为傲的校友，我们都已将您所需的一切汇集于此！从官方门户网站到学生活动，从研究出版物到社区服务，请尽情探索，发现 IIUM 的真正精彩之处。

本仓库汇集了马来西亚国际伊斯兰大学（IIUM）成员所需的各种资源。

阅读其他语言版本：English, Melayu, العربية, 日本語

引领未来 (LEADING THE WAY)

Section titled “引领未来 (LEADING THE WAY)”

目的

Section titled “目的”

本仓库旨在提供一份全面的资源清单，以造福 IIUM 学生。这包括学术资源、学生生活信息以及其他有用的链接。

如何使用

Section titled “如何使用”

要使用本仓库，只需浏览提供的文件和文件夹。每个文件夹包含不同类别的资源。点击提供的链接即可访问相应资源。

贡献

Section titled “贡献”

我们要欢迎所有人的贡献。如果您有资源想要添加或有改进建议，请遵循以下的贡献指南。

贡献指南

Section titled “贡献指南”
  1. Fork 本仓库。
  2. 为您的更改创建一个新分支（branch）。
  3. 在您的分支中进行更改。
  4. 提交包含您更改的拉取请求（pull request）。

我们感谢您的贡献，并期待在您的帮助下看到本仓库不断壮大！

Section titled “许可证”

文件夹结构

Section titled “文件夹结构”
  • Academic Resources: 包含与学术相关的资源，如教科书、在线课程和学习指南。
  • Student Life: 关于 IIUM 学生生活的信息，包括社团、活动和校园设施。
  • Campus Facilities: 关于校园可用设施的详细信息，如图书馆、自习室和体育设施。
  • Other Resources: 任何不属于上述类别的其他资源。

每个文件夹都包含一个 README 文件，其中包含有关该文件夹中资源的更多信息。

推荐

Section titled “推荐”

本部分为 IIUM 学生提供一系列推荐资源。

  • IIUM 课程表应用 - 一个基于网络的应用程序，可根据学生注册的课程生成时间表，由毕业生 Fareez Iqmal 制作。
  • Moodle 移动应用 / Moodle 桌面应用 - 由于 Imaalum 使用 Moodle，此应用程序允许学生访问他们的课程。
  • 活动 - IIUM 现有活动的列表。

IIUM 官方网站和门户

Section titled “IIUM 官方网站和门户”

本部分提供了一系列官方网站和门户，为 IIUM 社区提供各种服务。

  • 马来西亚国际伊斯兰大学 (IIUM) - 官方网站: 包含关于大学、愿景、使命、历史、管理、学院、中心、研究所、校区与其它的常规信息。
  • i-Ma’luum - 学生服务: 一个 基于网络 的系统，为学生提供重要的在线服务，如课程注册、考试成绩、财务报表、学术成绩单等。
  • i-Ta’leem - 学习管理系统: 支持在线教学活动，如课程材料、作业、测验、论坛等。
  • i-Viva - 研究生 Viva 流程: 管理研究生的 Viva 流程，如提名导师、提交研究计划、安排 Viva 会议等。

IIUM 学术资源和工具

Section titled “IIUM 学术资源和工具”

本部分提供与 IIUM 学术界相关的应用程序、工具和服务资源。

  • 通用学术资源 - 基本工具、作品集和图书馆链接。
  • KICT 资源 - 信息与通信技术资源。
  • Gombak 和 Kuantan 预注册 - 注册日期和时间表。
  • Pagoh 预注册 - Pagoh 校区的日期和时间表。

IIUM 校友网络和职业机会

Section titled “IIUM 校友网络和职业机会”

本部分提供与 IIUM 校友网络和职业机会相关的资源。

  • IIUM 校友门户 - 连接校友与母校，并提供信息和服务，如校友 Touch n Go 卡、校友回馈活动、校友画廊、校友成功故事等。
  • 校友 - 马来西亚国际伊斯兰大学 - 为校友提供信息和资源，如校友门户、校友名录、校友活动、校友福利等。
  • 校友关系部 - 管理校友关系和活动以及学生职业服务。它包括校友关系科 (ARS)、学生职业服务科 (SCSS)、IIUM 创业组 (IEU) 等部门。

IIUM 新闻和媒体

Section titled “IIUM 新闻和媒体”

本部分提供 IIUM 新闻和媒体报道的资源。

  • IIUM Today - 提供校园最新新闻和活动。涵盖学术、学生生活、激励、生活方式、观点、专题等主题。它还展示了传播学学生和教职员工的作品。
  • IIUM 新闻报道 - 收集并展示各来源提及 IIUM 的新闻文章。包括快讯、头条新闻、印刷新闻、官方新闻等类别。
  • 最新新闻 - 马来西亚国际伊斯兰大学 - 提供来自 IIUM 官方网站的新闻更新。包括公告、活动、成就等。

IIUM 研究和出版物

Section titled “IIUM 研究和出版物”

本部分提供 IIUM 研究和出版物的信息和服务。

  • IIUM 研究 - 提供 IIUM 研究活动的信息和服务。包括研究亮点、研究管理中心、研究集群、研究资助、研究伦理等。
  • 出版物 - 马来西亚国际伊斯兰大学 - 提供 IIUM 教职员工和研究人员的各种出版物信息和访问权限。包括精选出版物、书籍、期刊、会议论文等。
  • 研究管理中心 - 支持和促进 IIUM 的研究活动。包括研究发展组 (RDU)、研究监测组 (RMU)、研究出版组 (RPU) 等部门。

IIUM 社区服务和外展

Section titled “IIUM 社区服务和外展”

本部分提供 IIUM 社区服务和外展活动的信息和服务。

  • 社区参与和服务中心 (CENSERVE) - 为教职员工和学生提供规划和执行社区参与活动的平台。包括项目、俱乐部、计划、活动等。
  • CENSERVE – 社区参与和服务中心 - 展示 CENSERVE 的社区参与和服务倡议。包括新闻、画廊、地图、奖项、SDG 重点领域、合作伙伴等。

IIUM 文化和价值观

Section titled “IIUM 文化和价值观”

本部分提供有关 IIUM 文化和价值观的信息资源。

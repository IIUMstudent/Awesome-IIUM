> Where to go when you need help.

## 🧭 Guides

- [Health & Wellbeing](./health-and-wellbeing/) - Clinic, medical check-ups,
  insurance, counselling and disability support.
- [IT & Accounts](./it-and-accounts/) - Wi-Fi, passwords, i-Ma'luum and the ICT
  help desk.
- [Safety & Emergencies](./safety/) - Campus security and emergency numbers.

| Need help with…                         | Go to                                                                                   |
| :-------------------------------------- | :-------------------------------------------------------------------------------------- |
| Illness, medical check-ups              | [IIUM Sejahtera Clinic](https://centre.iium.edu.my/clinic/)                             |
| Stress, personal problems, career plans | [Counselling and Career Services Centre (CCSC)](https://centre.iium.edu.my/ccsc/)       |
| Disability support                      | [Disability Services Unit (DSU)](https://office.iium.edu.my/dsu)                        |
| Passwords, Wi-Fi, IT problems           | [ICT Help Desk](https://istack.iium.edu.my/)                                            |
| Housing, mahallah                       | [Residential and Services Department (RSD)](https://division.iium.edu.my/rsd/)          |
| Student activities, transport           | [Student Affairs and Development Division (STADD)](https://division.iium.edu.my/stadd/) |
| Registration, academic records          | [AMAD](https://division.iium.edu.my/amad/)                                              |
| Fees, payments                          | [Finance Division](https://division.iium.edu.my/finance/)                               |
| Scholarships, financial hardship        | [IIUM Endowment Fund (IEF)](https://division.iium.edu.my/ief)                           |
| Visa, student pass                      | [Office of International Affairs](https://office.iium.edu.my/international/)            |
| Security, lost items, emergencies       | [Office of Security Management (OSeM)](https://office.iium.edu.my/osem/)                |

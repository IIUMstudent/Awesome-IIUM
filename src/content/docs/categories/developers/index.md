> Open source projects, APIs, and tech communities within IIUM.

## 🛠️ APIs & Libraries

- **[iium_schedule](https://github.com/iqfareez/iium_schedule)** (`dart`) - A
  library to fetch IIUM course schedules and subject data.
- **[gomaluum](https://github.com/nrmnqdds/gomaluum)** - An unofficial API proxy
  for i-Ma'luum, enabling developers to build apps integrating with the student
  portal.

## 📱 Open Source Apps

- **[Simplified i-Ma'luum](https://github.com/nrmnqdds/simplified-imaluum)** - A
  modern, mobile-friendly interface for the student portal.
- **[IIUM Schedule Mobile App](https://github.com/iqfareez/iium_schedule)** -
  Mobile app for viewing class schedules and campus information.

## 📊 Data Analysis

- **[Overpass Turbo (IIUM Query)](https://overpass-turbo.eu/)** - Web-based data
  filtering tool for OpenStreetMap. Use it to "scrape" spatial data like "all
  cafes in IIUM" or "prayer rooms".

## 👥 Communities

- **[GDG on Campus IIUM](https://gdg.community.dev/gdg-on-campus-international-islamic-university-malaysia-selangor-malaysia)** -
  IIUM's Google Developer Groups chapter (formerly Google Developer Student
  Clubs): workshops, study jams, the Solution Challenge and side projects. Join
  through the chapter page.

## 🚀 Add Your Project

Built something for IIUM students? Make sure it's open source, then
[suggest it](https://github.com/iiumstudent/Awesome-IIUM/issues/new?template=resource-request.yml)
with the category **Developers**. No coding needed: it's added automatically
once a maintainer approves it.

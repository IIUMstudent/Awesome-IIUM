## Quick links

| Service              | Description                        | URL                                                 |
| :------------------- | :--------------------------------- | :-------------------------------------------------- |
| **Official Website** | University info, admissions        | [iium.edu.my/v2](https://www.iium.edu.my/v2/)       |
| **i-Ma'luum**        | Student hub: results, registration | [imaluum.iium.edu.my](https://imaluum.iium.edu.my/) |
| **i-Ta'leem**        | Moodle LMS (courses, assignments)  | [italeem.iium.edu.my](https://italeem.iium.edu.my/) |
| **Pre-Registration** | Course add/drop & schedules        | [prereg1.iium.edu.my](http://prereg1.iium.edu.my/)  |
| **MyApps**           | All IIUM apps directory            | [myapps.iium.edu.my](https://myapps.iium.edu.my/)   |

Awesome IIUM is run by students and is not an official IIUM website. For
anything that matters (fees, deadlines, rules), check the
[official sources](/Awesome-IIUM/categories/official-sources/).

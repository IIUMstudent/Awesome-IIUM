## 📡 Systems monitored

- **i-Ma'luum**: student portal (course registration, exam results).
- **i-Ta'leem**: the official LMS (learning management system).

Every 3 hours, and whenever the site is updated, a GitHub Actions job requests
each system's home page. Any reply counts as online. No reply within 15 seconds,
or a server error, counts as offline.

<Aside title="Unofficial check">
  This runs from outside IIUM's network. "Offline" means our bot couldn't reach
  the system, which doesn't always mean it's down for you.
</Aside>
